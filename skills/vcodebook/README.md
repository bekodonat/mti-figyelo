# vcodebook: write the coding scheme before you label

A skill for coding agents (the open SKILL.md format). Run `/vcodebook` in your project folder: it writes
`codebook.md` with the unit of observation, each code with a definition, an inclusion rule, a real example
and a near miss, the decision rules for boundary cases, a set-aside code and the hand-coding plan. Read-only
on your texts. Pair it with `/vclassify` (apply the codebook) and `/vcoder-agreement` (check the labels).
