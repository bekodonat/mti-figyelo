# vtable-format

Apply a standard academic table format to a manuscript's tables (vanilla): a caption above each table ("Table N. Title", six words at most, sequential numbering), header row bold and body plain, one font and size, sentence-case cells, consistent number formatting, a Note line for source and base, the three-line (booktabs) rule style, each table right after the paragraph that first cites it, parallel tables in one layout, core models in the main text and robustness in the appendix, no estimated counts. Audits first, applies on request.

Install: copy this folder into ~/.claude/skills/ and type /vtable-format in a Claude Code session. See SKILL.md for the full method.
