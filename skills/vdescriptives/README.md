# vdescriptives

Descriptive statistics for an empirical paper (vanilla): how to describe the data and show a few tables and figures relating the explanatory variable to the outcome BEFORE the model. Builds the presentation from the data or audits an existing one: the sample funnel, the outcome's distribution, its categories, the explanatory variable and the variation that identifies its effect, a bivariate preview, the summary statistics table, at most two figures, and an explicitly descriptive framing.

Install: copy this folder into ~/.claude/skills/ and type /vdescriptives in a Claude Code session. See SKILL.md for the full method.
